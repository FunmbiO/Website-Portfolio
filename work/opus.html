Opus

Opus is a personal assistant I built for my own email and subscriptions. It sorts my inbox, flags what needs a reply, drafts the replies, keeps an eye on what I'm paying for and puts anything with consequences in an approval queue. It never sends, deletes or cancels anything by itself. The demo here is a separate public build with made-up sample data and no server behind it. The real assistant is private and runs on my own machine.

What's in it

  • It can't send, delete, trash, label or cancel anything. The model only gets the tools in one file, none of them do those things, and a check script (npm run safety) fails if that changes.
  • Anything with consequences waits in an approval queue. Approving only makes Opus write out the steps for me. It still never cancels or sends for me.
  • It drafts replies into Gmail Drafts and flags what needs an answer, so I read and send them myself.
  • It watches its own cost. Cheap triage runs on Haiku, drafts run on Sonnet, bulk senders are sorted by plain rules for free, and there's a per-run cap and a spending alert.
  • The real one runs behind Tailscale with no port open to the internet, and the dashboard installs on an iPhone as a web app.
  • The demo on this site is a static build with sample data. It makes no network calls, so nothing in it is my real email or money.
