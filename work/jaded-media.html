Jaded Media

The website for my own photography and film business. It opens with one line, “Photo and film, let's make art.”, and puts the work first. Behind the public pages sits an admin area for managing content and video.

What's in it

  • Videos upload straight from the browser to Cloudflare R2 through short-lived signed URLs, so large files never pass through the app server.
  • Security was audited in a dedicated pass: a nonce-based Content Security Policy, HSTS, clickjacking protection, a locked-down Permissions-Policy, link-scheme checks on rendered markdown, and an hourly cap on admin email sending.
  • Legal, privacy, cookie-consent and accessibility work was done as its own phase and documented.
  • Runs on a custom domain, with a preview deployment for every branch before anything reaches production.
