Private file transfer app on AWS

NitroDrp

I got tired of paying for WeTransfer, so I built a prettier one. You upload big files, get an unguessable link, and pick an expiry, an optional password and a download limit. It runs on AWS from end to end: a Lightsail server for the app, S3 for the files, DynamoDB for the links and SES for emailing them. The live demo runs entirely in your browser, so nothing is actually uploaded.

What's in it

  • File bytes never touch my server. The API only signs URLs, and the browser sends 16 MiB parts straight to S3, so multi-GB files work. Each part retries and the upload resumes after a reload.
  • Links expire on their own. The API refuses expired links, DynamoDB TTL deletes the metadata and S3 lifecycle rules delete the files, so there's no cleanup job.
  • Download limits can't be beaten by racing. The count is one conditional database write, and a concurrency test backs it up.
  • It runs on a small always-on Lightsail server behind Caddy with automatic HTTPS. Terraform builds the AWS side, with its state in its own versioned S3 bucket.
  • Links can be emailed through Amazon SES. The sender gets the replies, the password is never in the email, and each link has a cap on how many it can send.
  • Sign in with Face ID or a fingerprint (passkeys) and see the same links on your phone and laptop. It also installs on a phone as a home-screen app.
  • “Download all” streams a .zip on the fly in flat memory, checked with a 4.8 GB archive.
